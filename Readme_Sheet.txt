The Project is about APSRTC_City_bus_transit of Visakhapatnam city. This work gives an insight of APSRTC's Performance overview over the past 5 years in the Visakhapatnam City Bus transit.

Dataset : The dataset is not readily available online. It is prepared using bunch of resources. Using the Data available online (News papers clippings, APSRTC's financial press notes published yearly, Wikipedia and some sources) the data set is prepared. The KPI parameters are calculated from the existing APSRTC RTI's. scaled down to daily level and used them to APSRTC Vizag city bus transit data.

What does the dataset contains: The dataset is an excel sheet prepared after continuous correlating with claude with factual data. The Claude AI data has been revamped nearly 6-7 times to get correct correlated data with all the sheets.
The data set contains 7 sheets

1) Route Master : The sheet gives information about total routes travelled by all the buses of APSRTC.It gives information about from and to terminals, bus stops,total buses deployed/day, total trips/day, total distances travelled by all buses/day,seating capacity, revenue by all buses/day, earning/km, km operated/day

2) Bus Master : The sheet gives information about Total number of buses, bus reg no's, bus types ,routes,fuel type, engine type and all bus related information of all city buses of APSRTC

3) Depot Summary : The sheet gives information about total depots in Visakhapatnam city, buses in each depot, owned + hired buses, routes operated, daily trips, revenue earned daily. All the parameters in routes based are extended to depot level. The total values and average values are cross checked with the route_master and daily_ops_log sheet

4) Daily_Ops_Log : It is observed that, the total number of trips/day of Vishakhapatnam city is around 2300+. Creating a database with daily trips of 2300+ over 5 years is not an efficient approach. Hence a day is considered and average value of parameters of the day is considered year wise for the 5 years. The present sheets discusses completely about the total trips for each for each route,total number of buses/day,time taken to travel, km travalled by each bus in each route,seating capacity and many parameters for successful deduction into KPI's

5) Yearly_Trend_RTI: The sheet gives an year wise approach of all key parameters in evaluating the performance of APSRTC_City_Bus_Fleet. all the parameters over the years are average values considering a day in an year.

6) Bus_stops_geo_coordinates : The sheet gives total number of bus stops,stop names and routes serve and landmarks. The data in this sheet is not used at present and could be useful for future prospectus in data analysis.
